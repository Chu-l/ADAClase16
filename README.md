# 📘 Ejercitación JavaScript – Clase 16

Este repositorio contiene los ejercicios prácticos realizados durante la **Clase 16** del curso de **Introducción a JavaScript**, enfocados en el uso de métodos avanzados de arrays para la manipulación y transformación de datos.

## 🧠 Conocimientos aplicados

- Métodos avanzados de arrays:
  - `map()`
  - `filter()`
  - `find()`
  - `reduce()`
  - `forEach()`
- Transformación y filtrado de datos
- Búsqueda de elementos según condiciones
- Acumulación y reducción de valores
- Trabajo con arrays de strings y de objetos
- Encadenamiento de métodos
- Uso de condicionales y lógica funcional
- Salida por consola

## 🛠️ Ejercicios desarrollados

- Creación de un nuevo array con valores transformados (`map`)
- Filtrado de elementos según una condición (`filter`)
- Búsqueda del primer elemento que cumple un criterio (`find`)
- Cálculo de totales y acumulaciones (`reduce`)
- Recorrido y visualización de elementos (`forEach`)
- Manipulación de listas de palabras y strings
- Construcción de frases a partir de arrays
- Análisis y transformación de listas de objetos
- Resolución de ejercicios combinando múltiples métodos
- Ejercicios extra de lógica funcional aplicada

## 🎯 Objetivo

Comprender y aplicar métodos avanzados de arrays en JavaScript para escribir código más expresivo, eficiente y legible, fortaleciendo la lógica funcional y la manipulación de datos sin utilizar librerías externas.
